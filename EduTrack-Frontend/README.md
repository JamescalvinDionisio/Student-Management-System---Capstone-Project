# EduTrack Frontend

Designed for the existing Node.js + Express + MySQL backend.

## Install
npm install

## Run
npm run dev

Open http://localhost:5173

Backend must be running at http://localhost:5000.

The frontend calls the existing endpoints for login, students, parents, academic records/performance, attendance, tasks, documents, communications, risk alerts, audit logs and users. JWT is automatically attached by src/api.js.
